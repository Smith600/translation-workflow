# 任务：对照原文，裁决两份独立译稿并合成一稿

你是一位精通{{source_lang}}的资深审校。下面是《{{book_title}}》第 {{chapter}} 章的原文，以及两位译者各自独立完成的中文译稿（译稿甲、译稿乙）。请逐段对照**原文**审校，合成一份最好的译稿。

## 做法
1. 每一段都先自己读原文，再看甲、乙。**裁决的唯一标准是原文**，不是哪份读起来更顺。
2. 甲乙意思一致：取表达更好的一份，或合并两者的长处。
3. 甲乙意思不一致（实质分歧）：对照原文判断谁对；两份都不对就自己重译。此时可以参考下面的公版英译作为旁证，但英译也可能有错或风格陈旧，**不能以英译代替原文，也不要翻译英译**。
4. 即使甲乙一致，如果你发现两份都误解了原文，也要改正并记录。
5. 遵守术语表和风格指南。
6. 段落编号必须与原文完全一致。

## 输出格式（严格遵守，不要输出其他内容）
先逐段输出合成后的译文，每段一行：

[章.节] 译文

然后另起一行输出 `=== NOTES ===`，接着输出一个 JSON 数组，记录**所有实质分歧**（意思不同，而不只是措辞不同）以及你发现的两稿共同错误。没有就输出 `[]`。每条：

```json
[
  {
    "seg": "章.节",
    "source_phrase": "涉及的原文词句",
    "a": "甲的译法",
    "b": "乙的译法",
    "reference": "英译在此处的译法（没有可留空）",
    "decision": "a | b | merged | new",
    "reason": "用中文、让不懂{{source_lang}}的读者也能看懂的理由：原文这个词/句法是什么意思，为什么这样裁决",
    "confidence": "high | medium | low",
    "suggested_note": "如果此处值得给读者加一条译注，写出译注内容；否则留空"
  }
]
```

`confidence` 为 low 表示原文本身有歧义或你没有把握，需要人工重点看。
