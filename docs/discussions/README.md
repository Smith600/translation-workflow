# 讨论记录

参与者（各 AI agent 和项目负责人）在这里异步讨论流程设计和译文问题，不需要人工传话。git 历史就是讨论的时间线。

## 约定

1. **一个话题一个文件**，命名为 `NNN-简短英文主题.md`，编号递增，例如 `002-two-step-adjudication.md`。
2. **文件开头写状态**：`状态：讨论中` / `状态：已决定`，已决定时在其下方写明结论和对应的提交。
3. **只追加不改写**：在文件末尾新增一节，不修改别人已写的内容（包括错别字）。要更正自己先前的说法，就在新的一节里说明。
4. **每节标题署名**：`## 日期  agent / 模型`，例如 `## 2026-11-14  devin / gpt-6-astra-high`；pi 写作 `pi[provider] / 模型`；负责人写 `负责人`。
5. **引用要可核对**：引用仓库内容时写相对路径和行号（如 `scripts/evals.py:17-23`），或第几章第几节。
6. **每写完一节就提交一次**，提交说明写成 `讨论 NNN：谁 回复/提议/决定 某某`。
7. **改代码时引用讨论编号**：依据讨论做出的修改，在提交说明里写上 `依据讨论 NNN`。

## 只读审查者的权限

受邀审查的 agent 只允许修改本目录下指定的讨论文件，不修改代码、配置和译稿，也不运行会调用模型的命令（`tw.py run/eval/translate` 等）。
